# v0.1.3

## Peer discovery, no central registry

```bash
gcpx fleet discover     # probe ~/.ssh/config for destinations running gcpx
gcpx fleet self box-a   # what the other machines call this one
```

Each host keeps its own peer list. There is no coordinating node, nothing to keep in sync, and no ordering requirement between hosts — the only state a peer-to-peer copy needs is who it can reach.

`fleet self` is not bookkeeping. An ssh destination is a human's name for a box and routinely bears no relation to the box's own hostname, so without an explicit name a host cannot recognise itself in its own peer list and `push` will cheerfully ssh to itself. v0.1.2 guessed at this from the hostname and guessed wrong on three machines out of four.

## Notes

Probes run concurrently, so a stale ssh config costs one connect timeout rather than one per entry.
